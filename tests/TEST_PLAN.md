# Test Plan

## Unit
Core rules, state transitions, identity and duplicate semantics.

## Integration
Linked records, operator pages, automation write paths and API boundary.

## Regression
Critical business scenarios after every structural change.

## Security
Secrets, permissions, technical-field exposure, destructive actions and automation recursion.

## Data safety
Duplicates, orphan links, migration reconciliation, export/import integrity and recovery.

## Release gate
All required suites pass and evidence is recorded in the technical layer.
