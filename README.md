# Airtable-B2B-BUSINESS

Компактная B2B-система в Airtable с пятисписочным операторским интерфейсом.

## Рабочая поверхность

**КОМПАНИЯ | ОЧЕРЕДЬ | КЛИЕНТ | ЗАКАЗ | АРХИВ**

КОМПАНИЯ — канонический реестр подготовленных компаний.
ОЧЕРЕДЬ — приоритетная проекция компаний, которые нужно обработать.
КЛИЕНТ — проекция договорившихся компаний.
ЗАКАЗ — заказы и повторные заказы компаний.
АРХИВ — проекция исключённых из рабочей очереди.

## Lead Acquisition

Поиск выполняется по контракту:
**сфера × потребность × источник × сценарий → identity → phone → need evidence → LPR role → dedup → READY LEAD**

В Airtable попадают только записи, прошедшие обязательный quality gate.
Сырые находки и неполные кандидаты не являются рабочими записями.

## Target data model

- КОМПАНИЯ
- ИСТОРИЯ КОНТАКТОВ
- ЗАКАЗЫ
- ИСТОЧНИКИ
- СФЕРЫ
- СКРИПТЫ

## Definition of Done

Манифест → дорожная карта → архитектурный контракт → модель данных → GitHub design → Airtable implementation → stage tests → integration/regression → security/data-safety → external acceptance → documentation → release audit.
