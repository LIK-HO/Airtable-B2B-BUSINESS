# СКРИПТЫ — B2B BUSINESS

## Принцип

СКРИПТЫ — справочник рабочих сценариев. Скрипт выбирается по сфере + типу потребности + этапу контакта.

Не использовать один универсальный сценарий для всех сфер.

## Структура записи скрипта

- Сфера;
- Сценарий;
- Когда применять;
- Цель;
- Открытие;
- 2–4 квалифицирующих вопроса;
- Основное предложение;
- Типовые возражения;
- Ответы;
- Следующий шаг;
- Когда перезвонить;
- Нельзя говорить.

## Базовая библиотека

### S01 — Стройматериалы / подъём

**Цель:** быстро выяснить, есть ли потребность в разгрузке/подъёме.

Открытие: «Добрый день. Подскажите, у вас сейчас есть объекты в Москве, где требуется разгрузка или подъём стройматериалов?»

Вопросы:
1. Какой материал и объём работ?
2. Это разовая поставка или объект продолжается?
3. Нужно только разгрузить или поднять/разнести по объекту?
4. На какую дату нужен персонал?

Предложение: «Можем дать людей под конкретную операцию без необходимости расширять штат».

Следующий шаг: дата, объём, адрес объекта и контакт ответственного.

### S02 — Генподрядчик / объект

**Цель:** выявить регулярные объектные работы.

Вопросы:
1. Какие работы чаще всего отдаёте внешним рабочим?
2. Где сейчас возникает нехватка людей?
3. Какой тип персонала нужен?
4. Есть ли ближайшие объекты, где нужен выход?

Следующий шаг: получить ближайшую потребность и срок.

### S03 — Монтажная компания

Открытие через оборудование/конструкции.

Вопросы: вес/габариты, место работ, этажность, необходимость такелажа, дата.

Предложение: грузчики/такелажники под конкретную монтажную операцию.

### S04 — Склад / разгрузка

Вопросы: количество машин, паллеты/штучный груз, пиковые дни, ночные/дневные смены.

Цель: получить регулярный объём.

### S05 — 3PL / фулфилмент

Акцент: пики и временное усиление.

Вопросы: сезонность, пики отгрузок, постоянная численность, аварийные замены.

### S06 — Склад маркетплейса

Акцент: пиковая нагрузка.

Вопросы: объём в пик, число смен, необходимость срочного выхода, требования к персоналу.

### S07 — Логистическая компания

Акцент: разгрузка/перегрузка.

Вопросы: тип груза, количество операций, график машин, нужна ли бригада по вызову.

### S08 — Мероприятия / выставка

Вопросы: тип мероприятия, дата монтажа, демонтаж, количество людей, наличие тяжёлых элементов.

Предложение: одна бригада на конкретный этап.

### S09 — Event-агентство

Акцент на повторяемость.

Вопросы: сколько мероприятий в месяц, какие операции закрываете своими силами, когда нужна внешняя бригада.

### S10 — Сцена / концерт

Вопросы: оборудование, время загрузки/разгрузки, монтаж/демонтаж, ограничения площадки.

### S11 — Магазин

Акцент: поставки, занос, переезды, открытия.

Вопросы: количество поставок, тяжёлый товар, есть ли собственные грузчики, ближайшее событие.

### S12 — Мебель / оборудование

Акцент: занос и установка.

Вопросы: вес/габариты, этаж, лифт, нужна ли помощь монтажникам.

### S13 — Офис

Акцент: переезд/перестановка/доставка.

Вопросы: дата, количество рабочих мест, мебель/техника, один адрес или несколько.

### S14 — Управляющая компания / БЦ

Акцент: периодические разовые задачи.

Вопросы: какие работы регулярно возникают, кто сейчас закрывает их, бывают ли срочные задачи.

### S15 — Сервисная компания

Акцент: усиление выездной бригады.

Вопросы: нужен ли второй/третий человек на объект, какие операции занимают больше всего времени, есть ли пики.

### S16 — Производство

Акцент: ручная погрузка/разгрузка без попытки оценивать финансовые показатели.

Вопросы: тип продукции, частота поставок, объём ручных операций, пики.

### S17 — Переезд

Вопросы: офис/магазин/склад, объём мебели, этажи, сроки.

### S18 — Первичный контакт без подтверждённой текущей потребности

Цель: выяснить ближайший вероятный сценарий, не навязывая услугу.

Вопросы: «Какие работы обычно отдаёте внешним бригадам?», «Когда следующий такой случай?»

### S19 — Перезвонить

Открытие: «Добрый день, договаривались вернуться к вопросу по [потребность]. Подскажите, актуально ли сейчас?»

Цель: получить конкретную дату или закрыть вопрос.

### S20 — Не дозвонились

Не считать звонок состоявшимся.

Следующий шаг: один повторный звонок в другой временной интервал; если реакции нет — АРХИВ.

### S21 — Уже есть подрядчик

Вопрос: «Понимаю. Бывает ли потребность в дополнительных людях на пик или срочные выходы, когда штатной бригады не хватает?»

Цель: получить резервный сценарий, а не спорить с действующим поставщиком.

### S22 — «Нам не нужно»

Короткий ответ: «Понял. Тогда только уточню: такие работы у вас вообще возникают или вы всегда закрываете их своими силами?»

Если возникают — записать сценарий и срок возможного возврата.

### S23 — Цена

Не называть неподготовленную цену без объёма.

Вопросы: количество людей, часы, тип работы, дата.

После уточнения — дать конкретное предложение.

### S24 — Получить контакт ЛПР

«Подскажите, кто у вас обычно принимает решение по привлечению грузчиков/такелажников/рабочих на такие задачи?»

Фиксируется должность; ФИО только если открыто сообщено/доступно.

## Запреты

Не использовать в скриптах:

- неподтверждённые обещания;
- выдуманные цифры;
- давление;
- фиктивные ссылки на клиента/заказчика;
- представление предположения как установленного факта.

Любой текст о потребности в карточке должен различать подтверждённую потребность и предположение.
