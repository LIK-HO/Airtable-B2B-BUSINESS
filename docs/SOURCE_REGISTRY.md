# ИСТОЧНИКИ — B2B BUSINESS

## Принцип

Это справочник источников для ручного/операторского поиска и проверки. Источники не являются рабочими списками и не создают записи автоматически.

Приоритет источника означает его полезность для конкретной задачи:

- A — идентичность/официальная проверка;
- B — сильный источник поиска и коммерческого сигнала;
- C — отраслевой/профессиональный источник;
- D — дополнительный сигнал, используемый только в совокупности.

## 8. Принцип использования источников

Источник не считается доказательством сам по себе.

Для КОМПАНИЯ используются:

**идентичность → ИНН/официальный реестр → контакт → источник контакта → потребность/сигнал → сфера → запись.**

При конфликте данных государственный источник имеет приоритет для идентичности, а карточки карт/коммерческие каталоги — приоритет для фактического телефона и коммерческого сигнала.

Не все источники должны использоваться для каждой компании.

Справочник содержит больше 50 источников намеренно, но рабочая выборка для конкретной сферы должна быть компактной.
