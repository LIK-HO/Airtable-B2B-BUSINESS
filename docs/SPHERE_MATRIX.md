# СФЕРЫ — B2B BUSINESS

## Принцип

СФЕРА — управляемый справочник направления поиска. Она не является отдельным лидом и не создаёт копии компании.

Ранжирование учитывает только бизнес-релевантность для текущей модели услуг:

1. вероятность потребности;
2. частота потребности;
3. доступность общего контакта;
4. соответствие типовым работам;
5. потенциальная повторяемость.

Бюджет компании не моделируется как показатель рейтинга.

## Поля СФЕРЫ

- Сфера;
- Родительская сфера;
- Приоритет;
- Типовые потребности;
- Типовые сигналы;
- Подходящие источники;
- Подходящий скрипт;
- Исключения;
- Примечание.

Сфера не должна содержать отдельные записи компаний.
